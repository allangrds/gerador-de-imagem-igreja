# Assets

Uma pasta por série (`3d/serie-01/`), cada uma com `manifest.json`:

```json
{
  "style": "descrição do estilo da série",
  "anchor": "arquivo que serviu de âncora de estilo",
  "assets": [{"file": "01-microfone.png", "use": "quando usar"}]
}
```

PNG com fundo transparente, 2048px ou mais. Antes de pedir um asset novo, procure aqui.
